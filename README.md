# QuizBowl iOS App

A SwiftUI client for the Obsidian quiz bowl buzzword analyzer. Search a
topic, browse extracted buzzphrases, and study them as flip flashcards
with AI-generated explanations.

## Requirements
- Xcode 15+
- iOS 17+ (adjust to your actual deployment target)
- The Obsidian Flask backend running (see the Quizbowl-Buzzphrase-Generator repo)
